# Nikon ND2 Driver Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A new `slideio-nd2` driver (id `ND2`) that opens Nikon `.nd2` files — chunked (Ver2.x/3.x) and legacy JPEG 2000 (Ver1.0) — one scene per acquired XY position, with Z/T from the experiment loop tree.

**Architecture:** Pure layers — `nd2::Variant` (CLX Lite and CLX XML decoders), `nd2::Attributes`/`nd2::Channels`, `nd2::Experiment` (loop flattening, frame index) — fed by two container readers, `nd2::ChunkFile` and `nd2::LegacyFile`, which each produce one `nd2::ImageInfo`. A thin `ND2Slide`/`ND2Scene` pair reads rows through an `nd2::FrameSource` (raw, zlib, JPEG 2000). Large downscaled reads go through LIF's tiled area filter, first moved into slideio-core.

**Tech Stack:** C++17, OpenCV, tinyxml2, zlib, nlohmann_json, slideio-core (`FileReader`, `readClampedBlock`), slideio-imagetools (`ImageTools::decodeJp2KStream`), Google Test, Python 3 for fixtures (stdlib; `imagecodecs` for the two legacy fixtures only).

**Spec:** `software-docs/specs/2026-11-12-nd2-driver-design.md` (cited as *D §n*). Format description: `D:/Projects/slideio/documents/image_formats/nd2/Nikon_ND2_Format.md` (*FD §n*); validation: `D:/Projects/slideio/documents/image_formats/nd2/validation/`.

## Global Constraints

- Driver id `ND2`; file spec `*.nd2`; `canOpenFile` does no I/O; `"ND2"` goes in `driverOrder` immediately before `"GDAL"`.
- Library `slideio-nd2` in `src/slideio/drivers/nd2/`; namespace `slideio::nd2` for internals; export macro `SLIDEIO_ND2_EXPORTS`, defined by `SLIDEIO_ND2_API`.
- Every error raised while opening starts with `ND2: ` and ends with `(file: <path>)`; a non-ND2 file gives `ND2: not a Nikon ND2 file (<reason>)`.
- Offsets and sizes are `uint64_t` with checked arithmetic; overflow is an error, never a wrap.
- Chunk-map `size` fields are never used; lengths come from chunk headers. Pixel start is always `chunkOffset + 16 + nameLength + 8`.
- Row stride is `uiWidthBytes`, never computed from the width.
- `uiSequenceCount` is never a count.
- Refused at open: `uiWidth/uiHeight/uiComp = 0`, `uiBpcInMemory ∉ {8,16,32}`, `uiWidthBytes` too small, `eCompression = 1`, tile size ≠ frame size, custom loop with count > 1, more than one T/XY/Z loop, `uiComp % channelCount ≠ 0`.
- `supportsConcurrentReads()` returns `true`; no `ContextPool`, no `thread_local`.
- Corpus suites are named `ND2Corpus*`; CI runs `slideio_nd2_tests --gtest_filter=-ND2Corpus*`.
- `src/tests/nd2/data/` is marked `-text` in `.gitattributes`.
- All commits go on `feature/nd2-driver`, never `master`.

## Review Focus

1. **A frame chunk past 4 GiB** (the 7 GB time-lapse). Addressing must use 64-bit offsets end to end — pinned in Task 3 (`Nd2ChunkFile.OffsetsAbove4GiB`, a sparse temp file).
2. **Channel subsets in any order on interleaved components**, e.g. `{2, 0}` on RGB — pinned in Task 7 (`Nd2Scene.ChannelSubsetOrder`).
3. **Releasing the file on Windows** after slide and scenes are dropped — pinned in Task 7 (`Nd2Scene.FileReleasedAfterClose`).
4. **Reading Z/T out of range** must throw with a message, not read a neighbouring frame — pinned in Task 7 (`Nd2Scene.OutOfRangePlaneThrows`).
5. **A partial-width read of a padded RGB row** at the right edge must not pick up padding bytes — pinned in Task 7 (`Nd2Scene.RightEdgeOfPaddedRow`).

**Interfaces:**
- Produces: the fixtures below and the pixel function every test relies on (copy exactly; Task 7 mirrors it in C++):

```text
v = x + 3*y + 17*k + 31*frame + 7*salt         k = component index within the frame
uint types: v mod 2^bits                       float32: v + 0.5
```

`frame` is the ND2 frame index (`ImageDataSeq|frame!`); `salt` = 0 unless stated. Padding bytes are `0xEE` so a read that touches them is visible.

Chunked writer per FD §3: signature chunk (`nameLength 32`, `dataLength 64`, `VerM.m`), metadata chunks, `ImageDataSeq|N!` frames (8-byte float64 time `N*100.0` ms, then pixels), `CustomData|AcqTimesCache!` (same times), map chunk last (name, u64 offset, u64 size = data length) with the 40-byte trailer as its final bytes. "Aligned" = chunks start on 4096 and frame `nameLength 4072`; "unpadded" = `nameLength` = name length. Metadata in CLX Lite for Ver3, CLX XML for Ver2, each wrapped (`SLxImageAttributes`/`no_name`). Default: 16×12, uint8, 1 channel, `dCalibration 0.5` (`bCalibrated` true), `dObjectiveMag 20`, `dTimeAbsolute 2460000.5`, channel `sDescription "DAPI"`, `uiColor 0x0000FF`.
